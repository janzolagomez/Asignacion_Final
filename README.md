# Extracting and Visualizing Stock Data

**Desarrollado por**: John Anzola

Este proyecto forma parte de un ejercicio de ciencia de datos. En él, se extrae un conjunto de datos de acciones de empresas, y luego se visualizan los datos utilizando gráficos. La visualización de los datos es una parte esencial del análisis de datos, ya que permite tomar decisiones informadas basadas en la información extraída.

## Objetivo

El objetivo de este proyecto es extraer datos financieros relevantes de un conjunto de acciones y mostrar estos datos visualmente para permitir una toma de decisiones más efectiva. Se utilizan herramientas y bibliotecas de Python para manipular y visualizar los datos.

## Archivos del Proyecto

- `StockDataExtraction.ipynb`: Notebook de Python donde se extraen y visualizan los datos de acciones. Incluye todo el proceso, desde la carga del conjunto de datos hasta la visualización de los resultados en gráficos.
